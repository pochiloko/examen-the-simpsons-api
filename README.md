# The Simpsons API - Buscador de Personajes
¡Bienvenidos a **The Simpsons API - el buscador de personajes de los simpsons**!  
Este programa, diseñado para fans de Los Simpsons, es una aplicación sencilla y en desarrollo, pensada para que puedas explorar y conocer las características principales de tus personajes favoritos.
## ¿Qué es este programa?
Es una herramienta de libre uso, abierta para todo público, que te permite buscar personajes de Los Simpsons de manera fácil y rápida, usando información extraída de una API confiable y gratuita.
## Fuente de datos
La información que muestra proviene de la API oficial:  
[The Simpsons API](https://thesimpsonsapi.com/#docs)  
Es totalmente gratuita y libre para uso público.
## Cómo usarlo
- Escribe el nombre del personaje que quieres buscar en el buscador.  
- Marca a tus personajes favoritos para tenerlos siempre a mano.  
- Accede a la sección de favoritos para ver y gestionar tu lista personalizada.
